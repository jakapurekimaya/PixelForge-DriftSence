# PixelForge-DriftSence

A computer vision-based system for **drift detection, severity assessment, and localization**.

## 📌 Project Overview

PixelForge-DriftSence is a computer vision system designed to detect visual drift between a reference image and a search image.

The system generates and analyzes image pairs to identify differences, determine the severity of the detected drift, and localize the affected region.

## 🎯 Objectives

- Detect visual drift between reference and search images.
- Generate different types and levels of drift.
- Classify the severity of drift.
- Localize the region where drift occurs.
- Evaluate the performance of drift detection and localization.
- Visualize the detected results.
